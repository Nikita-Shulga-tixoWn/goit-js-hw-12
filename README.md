# 🔍 Image Search Application

## 📌 Project Description

**EN:**  
JavaScript application for searching images using an external REST API.  
The project demonstrates working with asynchronous requests, dynamic data rendering, pagination, and user interaction.  
Developed as part of the GoIT Full-Stack Developer course.

**UA:**  
JavaScript-застосунок для пошуку зображень із використанням зовнішнього REST API.  
Проєкт демонструє роботу з асинхронними запитами, динамічним рендерингом даних, пагінацією та взаємодією з користувачем.  
Розроблено в межах курсу GoIT Full-Stack Developer.
